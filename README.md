# Keys99 CRM

Channel Partner CRM for real estate: leads, customers, bookings and commissions.

**Stack:** Next.js 14 (App Router) · TypeScript · Tailwind CSS · Recharts · lucide-react

## Screens built
- `/` Dashboard
- `/leads` Leads Management (with Lead Details drawer)
- `/customers/[id]` Customer Profile

Data is mock data in `src/lib/data.ts` for now; Supabase integration is next.

## Run
```bash
npm install
npm run dev
```
